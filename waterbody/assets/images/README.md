# Image Assets

Place your image assets in this directory.

## Optional Images

| Filename | Size | Description |
|----------|------|-------------|
| `logo.png` | 512x512 | App logo |
| `water_drop.png` | 256x256 | Water drop icon |
| `onboarding1.png` | 400x400 | Onboarding illustration 1 |
| `onboarding2.png` | 400x400 | Onboarding illustration 2 |
| `onboarding3.png` | 400x400 | Onboarding illustration 3 |
| `empty_state.png` | 300x300 | Empty state illustration |

## Notes
- The app uses emoji fallbacks if images are not present
- PNG format recommended for transparency support
- Consider adding 2x and 3x versions for different screen densities
