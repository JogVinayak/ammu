# Sound Assets

Place your reminder sound files in this directory.

## Required Files

| Filename | Description |
|----------|-------------|
| `bell.mp3` | Default bell ring sound (required) |
| `water_drop.mp3` | Water droplet sound |
| `chime.mp3` | Gentle chime sound |
| `ocean.mp3` | Ocean wave sound |
| `ding.mp3` | Soft ding sound |
| `bubbles.mp3` | Bubble sounds |

## Supported Formats
- MP3 (recommended)
- WAV
- AAC
- M4A
- OGG

## Recommendations
- Keep files under 500KB for quick loading
- Duration: 1-3 seconds
- Clear, pleasant sounds that aren't startling
- Royalty-free or licensed audio
